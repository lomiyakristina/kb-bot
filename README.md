# Живой жар — бот Красногорских бань

Консьерж комплекса в Telegram: разряды с фото, тариф, окна сеанса, заявка на бронь и статус гостя.

Главный администратор — Кристина. Как открыть папку в Cursor и править бота: `КАК-ЗАПУСТИТЬ.md`. Живой бот — @krasnogorsk_banya_bot. Второго не создавать.

Кристина просила меню, в котором нажатие открывает женский разряд, мужской разряд, тарифы, расписание паров и контакты. Бот это делает и добавляет бронь с подтверждением администратора и геймификацию «жар».

## Концепция

Комплекс узнают по живым экранам в залах. Бот — такой экран до прихода.

Гость не листает сайт с телефона в раздевалке. Он нажимает разряд, видит зал, выбирает окно на 4 часа и оставляет заявку. Место появляется, когда администратор нажимает «Подтвердить».

Жар — это не скидки и не «последний билет». Это лестница гостя:

| Ступень | Угольки | Что это даёт |
|---|---|---|
| Искра | 0 | Первый вход |
| Уголёк | 30 | Уже смотрел разряды |
| Жар | 90 | В заявке виден статус своего гостя |
| Пар | 180 | Пометка «свой пар» для администратора |
| Хранитель | 320 | Встречают по имени из бота |

Угольки капают за первый заход, просмотр разрядов, тариф, расписание, ритуал дня и заявку. Подтверждённый визит даёт ещё 40. Если гость не пришёл, администратор снимает визит — бонус за подтверждение тоже снимается.

Знаки: «Первый заход», «Два берега», «Свой стол», «Первый пар», «Вернулся», «Три ритуала».

Комплименты и бесплатный чай бот не обещает. Это решение комплекса на ресепшен, не автоматическая акция.

## Что на кнопках

- Женский разряд — фото и текст, дальше бронь
- Мужской разряд — фото и текст, дальше бронь
- Тарифы — прайс с сайта
- Расписание паров — авторский пар каждые 1,5 часа, с 10:00 до 22:00
- Забронировать — разряд, день, окно, число гостей, имя, телефон
- Мой жар — ступень, знаки, ритуал дня
- Контакты — адрес, телефон, маршрут, сайт, WhatsApp

Отдельно: семейный разряд, ресторан и лист ожидания на залы со статусом «скоро открытие» (зал, спа, высший, премиум сьют).

## Как запустить

1. В Telegram откройте @BotFather → `/newbot` → имя, например «Красногорские бани» → username, например `krasnogorsk_banya_bot`.
2. Скопируйте токен.
3. В этой папке:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

4. В `.env` вставьте токен. `ADMIN_IDS` можно оставить пустым на первый запуск.
5. `python main.py`
6. Откройте бота, нажмите `/whoami`, впишите этот id в `ADMIN_IDS`, перезапустите `python main.py`.

Заявки приходят администратору с кнопками «Подтвердить» и «Нет места». После подтверждения у той же карточки есть «Гость не пришёл». Гость может отменить заявку, пока её не подтвердили. Одновременно у человека не больше трёх новых заявок.

Филиал START БАНИ в Опалихе этот бот не бронирует.

## Мини-приложение

Экран гостя без App Store: те же разряды, тариф, пар, сертификат и заявка. Кнопка «Залы» в боте появится, когда в `.env` будет публичный `WEBAPP_URL` на https. Пока адреса нет, смотреть локально:

```bash
source .venv/bin/activate
python webapp.py
```

Открыть http://127.0.0.1:8787 . В этом просмотре заявка администратору не уходит. Новый бот не создавать.

## Перед показом гостям

- Сверить прайс с администрацией и поправить `content.py`, если цифры сменились
- Сверить часы пара в `STEAM_TIMES` с экранами в зале
- Проверить, что семейный разряд уже принимает гостей. На сайте у него нет плашки «скоро», поэтому бронь по нему включена
