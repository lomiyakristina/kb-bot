# Как запустить бота «Живой жар»

Это бот Красногорских бань в Telegram. Гость нажимает женский или мужской разряд, смотрит тариф и расписание паров, оставляет заявку. Заявка приходит тебе. Место появляется, только когда ты нажимаешь «Подтвердить».

Бот не обещает скидки, чай и «последнее место». Комплимент на ресепшен остаётся решением комплекса.

Пока программа запущена на компьютере — бот отвечает. Закрыла крышку ноутбука — бот молчит. Для проверки этого достаточно. Когда будешь готова пускать гостей круглые сутки, напиши Даше: бота поставим на сервер, чтобы он не зависел от твоего компьютера.

---

## Сначала посмотри без Telegram

Открой файл `preview.html` двойным щелчком. Это те же экраны, что увидит гость: разряды, тариф, бронь, контакты.

---

## Свой бот в Telegram

1. В Telegram открой @BotFather.
2. Напиши `/newbot`.
3. Имя, которое видят люди: `Красногорские бани`.
4. Username латиницей, обязательно на `bot` в конце. Например `krasnogorsk_banya_bot`. Если занято — BotFather попросит другой.
5. Он пришлёт токен: длинная строка с двоеточием. Это ключ от бота. Никому, кроме себя, его не пересылай.

Токен принадлежит тебе. Чужой бот для комплекса не нужен.

---

## Запуск на Маке

Открой Терминал. Команды по очереди, папку подставь ту, куда распаковала архив:

```bash
cd ~/Desktop/бот-красногорские-бани
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
open -e .env
```

В файле `.env` вместо `сюда_токен` вставь токен от BotFather. Строку `ADMIN_IDS` пока не трогай. Сохрани файл.

Дальше в том же окне Терминала:

```bash
source .venv/bin/activate
python main.py
```

Окно не закрывай. Пока оно открыто, бот живой.

В Telegram найди своего бота по username и нажми «Старт».

---

## Ты — администратор

1. В боте напиши `/whoami`. Он пришлёт твой числовой id.
2. Останови программу в Терминале: Ctrl+C.
3. Открой `.env` и впиши этот id в `ADMIN_IDS`. Если администраторов несколько — id через запятую.
4. Снова `python main.py`.

Проверь на себе: «Забронировать» → разряд → день → окно → имя и телефон. Заявка должна прийти тебе в этот же чат с кнопками «Подтвердить» и «Нет места». После подтверждения гость видит, что место есть. Если человек не пришёл — на карточке есть «Гость не пришёл».

Команда `/admin` показывает новые заявки. `/cancel` закрывает незаконченную бронь.

Пока в `ADMIN_IDS` пусто, заявка записывается, но тебе не приходит.

---

## Что поправить, если цифры сменятся

Цены, часы пара, тексты залов и контакты лежат в `content.py`. Адрес там как на сайте комплекса. Не меняй файл наугад: открой папку в Cursor и напиши, что именно поменять.

Ссылку на бота гостям не отправляй, пока сама не прошла бронь и не увидела заявку у себя.
